1. Create a new GitHub repo, upload ALL of these files (keep the folders, incl. .github/workflows).
2. Edit drive_link.txt: replace the text with your Drive share link (Anyone with the link).
3. Actions tab -> "Build game with OBB importer" -> Run workflow. Download the artifact (a zip) when it finishes.
4. Uninstall the old game on the TV, install SuperMegaBaseball-TV-OBB.apk.
5. Open the new "Import OBB" tile, tap "Download from Drive link", wait for "Done!", then launch the game.
